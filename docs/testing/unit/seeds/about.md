# About Seeds for Unit Tests

## Why We Use These

1. **Planning**: Pins down the "what" before getting swayed or distracted by the "how"
1. **Expandability**: Makes it simple to add new scenarios and contexts
1. **Consistency**: Ensures all tests follow the same predictable structure
1. **Clarity**: Keeps each test section easy to skim
1. **Navigation**: Establishes a clear hierarchy to make tests easier to find
1. **Documentation**: Leverages a semantic structure to allow each test to state an expectation in a somewhat natural language
